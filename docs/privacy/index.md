本政策说明你在访问**机场VPN**（[jichang-vpn.com](https://jichang-vpn.com)，以下简称“本站”）时，哪些信息会被处理、由谁处理。

## 一、本站自身收集的信息

1. **不设注册与登录**：本站是纯静态网站，没有账号系统、评论系统或表单，不会要求你提供姓名、邮箱、手机号等个人信息。
2. **服务器访问日志**：网站托管平台（如 Cloudflare Pages / GitHub Pages）可能会自动记录标准访问日志，例如 IP 地址、浏览器类型、访问时间和访问的页面。这些日志由托管平台按其隐私政策处理，主要用于安全防护和故障排查。
3. **统计分析**：本站目前**没有**接入第三方统计或广告追踪代码。如果以后接入，会在本页更新说明。

## 二、浏览器本地存储

- 本站会用浏览器的 `localStorage` 记住你选择的浅色或深色主题。这些信息只保存在你自己的浏览器里，不会上传。
- **实用工具全部在本地运行**：套餐筛选、倍率换算、订阅链接检查等工具都在你的浏览器里计算。你粘贴的订阅链接**不会**发送到本站服务器。即便如此，也请不要在任何网站上随意粘贴完整的订阅链接，因为它相当于你的账号凭证。
- 「复制优惠码」功能只会把优惠码写入你的剪贴板，不会读取剪贴板里原有的内容。

## 三、推广链接与第三方网站

- 本站的部分「访问官网」按钮属于推广（返佣）链接。点击后，你会跳转到对应品牌的网站。链接里带有推广标识（例如 `code=` 参数），品牌方会据此识别你是从本站来的，并可能在其网站上设置 Cookie。
- 你在品牌网站上注册、付款、使用服务时提供的所有信息，都由该品牌方收集和处理，适用**该品牌自己的隐私政策**，本站无法获取，也不承担责任。
- 本站还链接到 GitHub、客户端项目主页等第三方网站，它们同样有各自独立的隐私政策。

## 四、政策更新

如果本站的数据处理方式发生变化（例如接入统计工具），我们会更新本页并修改上方的修订日期。如有疑问，可以先阅读 [关于本站](/about/) 了解本站的运营方式。
