无论是使用 Clash Verge、Shadowrocket 还是 v2rayN，所有科学上网用户几乎都经历过这种崩溃的场景：
- 打开客户端点击延迟测速，**所有节点清一色显示红色“超时 (Timeout)”或“-1ms”**；
- 明明昨天还好好的，今天突然一个海外网页都打不开；
- 浏览器提示 *“代理服务器没有响应 / ERR_PROXY_CONNECTION_FAILED”*。

节点全红，到底是自己电脑/手机的问题？还是本地运营商（电信/移动/联通）宽带的问题？亦或是机场真的“跑路”了？

请不要慌张！根据我们多年的运维统计，**超过 85% 的“全红断连”情况实际上是由本地配置冲突或简单的订阅更新延迟引起的**。只需按照本文整理的 **“6 步黄金排查法则”**，便能快速定位根源并一键恢复网络。

## 一、节点全红的 6 步排查与自救流程

请由简入繁，依次执行以下 6 项排查：

```
┌────────────────────────────────────────────────────────┐
│                   节点全红快速排查流                    │
├───────┬────────────────────────────────────────────────┤
│ 步骤 1 │ 检查账号状态：套餐是否到期？流量是否耗尽？     │
├───────┼────────────────────────────────────────────────┤
│ 步骤 2 │ 校准系统时间：本地时钟偏差超过 90 秒会导致握手失败│
├───────┼────────────────────────────────────────────────┤
│ 步骤 3 │ 强制更新订阅：拉取机场最新的入口解析与备用 IP │
├───────┼────────────────────────────────────────────────┤
│ 步骤 4 │ 检查本地杀毒与代理端口占用（7890/10809 冲突） │
├───────┼────────────────────────────────────────────────┤
│ 步骤 5 │ 排查 DNS 污染与重置 TUN 虚拟网卡               │
├───────┼────────────────────────────────────────────────┤
│ 步骤 6 │ 查阅官方公告：确认是否遭遇骨干网割接或跑路风险│
└───────┴────────────────────────────────────────────────┘
```

### 第一步：登录机场后台，确认套餐与流量状态
打开手机 4G/5G 移动流量，登录您所购买的机场官方网站用户中心：
1. **检查订阅是否已过期**：很多用户设置了自动续费但扣款失败，或者忘了套餐到期日；
2. **检查流量是否已耗尽**：如果当月配额 100GB 已用满，系统会自动停用节点接入；
3. **检查账户是否被风控**：若同一账号短期内多地异常并发，可能被系统临时限制。

### 第二步：校准本地电脑与手机的系统时间（关键高发原因！）
现代安全代理协议（如 VMess、VLESS、Trojan、ShadowTLS）在建立 TLS 加密握手时，**严格依赖时间戳验证**。
- **排查标准**：如果您的电脑系统时钟与北京标准时间（NTP 时间）**偏差超过 90 秒**，服务器会基于防重放攻击机制直接丢弃所有通信包，导致客户端内**所有节点测试全部显示超时！**
- **解决方法**：进入 Windows / macOS 的【日期和时间设置】，点击 **【立即同步 (Sync Now)】** 按钮，确保与网络时间完全同步。

### 第三步：强制更新客户端内的订阅链接
节点可能没有坏，而是机场运维团队更换了被防火墙污染的国内入口 IP。
- 在 Clash Verge Rev 中：右键点击订阅卡片，选择 **【重新下载 / 强制更新】**；
- 在 Shadowrocket 中：在主界面按住屏幕向下滑动，触发全量更新；
- 在 v2rayN 中：点击 `订阅分组` -> `更新全部订阅`。
> [!NOTE] 提示
> 如果直接更新失败，请切换手机热点网络重试，或者打开本站提供的 [订阅链接格式检查器](/tools/subscription-checker)，在线检测该订阅链接在外部网络下是否依然有效。

### 第四步：检查本地代理端口占用与安全软件拦截
1. **端口冲突**：如果之前安装运行过其他代理软件（如百度网盘加速、老旧 VPN、迅雷等），可能会霸占 Clash 默认的 `7890` 混合端口或 v2rayN 的 `10809` 端口。可以在客户端设置中将端口修改为其他数值（如 `7899`）；
2. **杀毒软件防火墙**：某些杀毒软件（如 360 安全卫士、火绒或 Windows Defender）在静默升级后，可能会拦截 Mihomo 或 Xray 内核的联网权限。尝试暂时关闭第三方防护软件测试。

### 第五步：排查 DNS 污染与重启 TUN 虚拟网卡
很多用户遇到“节点延迟测试全绿，但网页依然打不开”，这是典型的 **DNS 劫持或 TUN 网卡假死**。
- **一键重置网卡**：在 Clash Verge Rev 中，先关闭 `TUN 模式`，再重新开启；
- **清理本地 DNS 缓存**：
  - Windows：打开 CMD 命令提示符，输入 `ipconfig /flushdns` 并回车；
  - macOS：打开终端终端，输入 `sudo dscacheutil -flushcache; sudo killall -HUP mDNSResponder`。

### 第六步：查阅机场公告，确认是否存在不可抗力
如果通过以上排查均无法解决，很可能是机房端遭遇了不可抗力：
1. **海缆中断或国内入口割接**：进入机场的官方 Telegram 交流群或公告频道，查看是否有节点维护公告；
2. **查阅站内时间线**：您也可以直接访问本站维护的 [行业维护与公告时间线](/tools/timeline)，实时追踪行业骨干网动态；
3. **启动备用节点方案**：若确认是该服务商集体宕机，请启用提前备好的按量计费不限时备用节点。

## 二、如何彻底预防“断网失联”焦虑？

资深用户的最佳防灾经验就是：**始终在客户端中保留一家第二品牌的备用订阅**。

当主力机场遭遇突发网络割接或运营商封锁时，只需在客户端列表中轻点一下，切换到备用节点的线路，工作与学习节奏丝毫不受影响。
