## 一、Shadowrocket（小火箭）对机场节点的独特偏好

相较于桌面端客户端，移动设备处于更复杂的网络环境（4G/5G 蜂窝数据与 WiFi 频繁切换）。因此，优秀的“小火箭专属机场”必须具备以下特质：

1. **瞬时重连机制优秀（零断流感）**：当用户走出电梯、从 WiFi 切换到 5G 移动网络时，代理协议必须能秒级恢复连接。基于 **IPLC/IEPL 纯专线** 的网络由于丢包率低，在移动端切换时几乎感受不到卡顿。
2. **移动端纯净住宅 IP 与原生流媒体支持**：手机用户大量使用 **TikTok 国际版、Instagram、Twitter/X 以及手机端 ChatGPT App**。这些应用极其依赖无污染的原生住宅 IP，若节点被标记为机房公有云广播 IP，轻则降质限速，重则直接封禁账号。
3. **原生二维码与一键托管导入（免手动逐条添加）**：小火箭支持标准的订阅链接托管格式。优质机场在后台提供一键“导入到 Shadowrocket”或扫码即导入功能，支持自动同步节点倍率与名称变更。

### 1. 优先选择全专线（IPLC / IEPL），避免公网直连
公网直连节点在手机 4G/5G 信号弱时极易引发重传，进而导致小火箭后台频繁唤醒 CPU 进行 TLS 握手，使 iPhone 迅速发热且电量暴跌。全专线机场不仅延迟极低（通常 20~40ms），而且极度节省手机电量。

### 2. 节点必须覆盖主流亚洲与美欧核心区域
小火箭日常使用时：
- **香港（HK）/ 台湾（TW）节点**：延迟最低（20ms 左右），非常适合日常网页浏览、YouTube 4K 即时响应以及微信/海外应用混合访问；
- **日本（JP）/ 新加坡（SG）节点**：网络纯净度高，适合 ChatGPT、Claude 以及日服游戏；
- **美国（US）节点**：TikTok、海外银行、电商独立站等必选地区。

### 3. 支持标准的“配置 (Config)”与分流规则
在小火箭的全局路由中，务必选择 **“配置 (Config)”** 模式，切勿长期开启“代理 (Proxy)”全局模式。优秀的机场会为小火箭提供专属的分流规则集，国内 App 走本地直连，海外应用自动分流，完全不影响微信和支付宝的使用。

## 三、Shadowrocket 极速上手与优化设置

只需简单四步，即可让您的小火箭发挥最佳性能：

1. **导入订阅**：复制机场后台提供的 Shadowrocket 专用订阅链接，打开小火箭，App 会自动感应剪贴板并提示添加；或者点击右上角 `+` 号，类型选择 `Subscribe`，粘贴链接并点击完成。
2. **测试节点连通性**：在首页点击 `连通性测试`，优先选用延迟最低且不显示超时的绿色节点。
3. **设置路由为配置模式**：在首页将全局路由从“代理”修改为 **“配置 (Config)”**，实现智能分流。
4. **开启自动更新订阅**：进入底部 `设置` -> `订阅` -> 开启 `打开时更新`，确保手机每次启动小火箭时自动拉取最新的健康节点列表。

## 五、iOS 用户常见疑问 (FAQ)

### Q1：App Store 里搜索到的“免费 Shadowrocket”是真的吗？
**不是，绝大多数是山寨或钓鱼软件**。正版 Shadowrocket 的开发者是 `Pan XiaoFei`，图标为一个黄色小火箭背景，并且为付费买断制 App（售价 $2.99），仅能在非中国大陆地区的海外 Apple ID 应用商店购买下载。

### Q2：小火箭连接后为什么微信消息有时候收不到？
通常是因为误开启了“全局代理 (Proxy)”模式，导致微信与国内推送服务器的连接绕道海外节点，受到防火墙干扰。只需将全局路由模式切换回 **“配置 (Config)”** 即可彻底解决。
