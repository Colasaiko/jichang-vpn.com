对于苹果 iPhone 和 iPad 用户来说，使用机场服务的第一道门槛往往不是买套餐，而是**“怎么在 App Store 里下载客户端”**。

由于国内 App Store 下架了网络代理工具，新手常被要求去外区注册美区 Apple ID 并折腾海外信用卡购买 $2.99 的小火箭（Shadowrocket），门槛极高。

好消息是，进入 2026 年，苹果生态已经形成了**“Nextin 官方直装派”**与**“小火箭外区付费派”**两大路径。本文为你带来两种路径的完整获取方式、费用明细、订阅导入实操与成功检查指南。

## 二、路径 A：通过 Nextin 快速上手 (零费用、免外区账号)

如果你使用的机场是本站推荐的主力品牌，直接使用配套的 **Nextin** 是最轻松的方案：

### 1. 在 App Store 快速安装 Nextin (6步指引)
1. 打开 iPhone 桌面的 **「App Store」** ➔ 点击右上角头像 ➔ 滑动到底部点击 **「退出登录」**；
2. 输入官方提供的专属账号密码登录 ➔ 提示安全双重认证时选择 **「其他选项」** ➔ 保护账户弹窗选择 **「不升级」**；
3. 在 App Store 搜索框输入 **`Nextin`** 直接下载安装；
4. 下载完毕后退出该账号，换回你自己的日常 Apple ID 即可，软件永久可用！

### 2. 账号密码一键直登与同步专线
1. 打开 Nextin 极光绿欢迎页，输入品牌站点识别码点击下一步；
2. 填写你在品牌官网注册购买时使用的 **邮箱** 与 **密码**，点击「登入」；
3. 系统自动同步下发最新的纯物理 IPLC 专线节点池，无需手动配置任何订阅链接！

---

### 3. 授权 iOS 系统级 VPN 描述文件 (核心必做)
1. 登入后进入主界面，轻触正中央大圆钮「未连接」；
2. 界面弹出“VPN 设置与隐私”说明，点击 **「继续」**；
3. **关键步骤**：iOS 系统弹出安全警报：““Nextin”想添加 VPN 配置”；
4. **必须点击右侧的「允许」按钮**，并验证 iPhone 的 **面容 ID (Face ID) 或锁屏密码** 完成授权；
5. 手机状态栏右上角出现 **VPN** 图标，即代表安全加密专线已接通。

## 三、路径 B：通过 Shadowrocket (小火箭) 导入通用订阅

如果你购买的是普通第三方无专属客户端的机场，需要走传统小火箭路线：

1. **准备外区 Apple ID**：自行注册一个美区 Apple ID，或者先用本站的 [免费美区 Apple ID](/tools/free-us-apple-id) 临时下载；
2. **付费购买软件**：美区售价为 **$2.99**（需通过美国 PayPal、海外信用卡或美区 Apple 礼品卡充值）；
3. **在 App Store 搜索下载**：务必认准开发者为 `PanGuoKe`、图标为浅蓝底白色火箭的正版软件；
4. **导入订阅链接**：
   - 在机场用户中心点击「复制通用订阅链接」；
   - 打开小火箭，点击右上角 **「+」** 按钮；
   - 类型选择 **「Subscribe (订阅)」**；
   - 在 URL 输入框中粘贴刚才复制的订阅链接，备注填写机场名字；
   - 点击右上角「保存」，软件会自动下载节点列表；
5. **分流模式设置**：
   - 全局路由（Global Routing）务必选择 **【配置 (Config)】**，切勿选成代理（Proxy）；
   - 打开主开关，按照系统提示输入锁屏密码允许添加 VPN 配置。

## 四、iPhone 连接成功检查与防坑要点

1. **检查顶部状态栏**：必须显示 **VPN** 小图标；
2. **海外测试**：打开 Safari 访问 `https://www.google.com` 确认即时响应；
3. **国内直连测试**：打开微信发消息、打开网易云音乐听歌，确认不受任何延迟影响；
4. **⚠️ 避坑提醒**：千万不要在 iPhone 的系统「设置」中直接登录下载用的 Apple ID（防止 iCloud 数据被同步），**必须且只能在 App Store 内部登录**！
