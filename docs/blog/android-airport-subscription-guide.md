在安卓（Android）手机上使用机场服务，虽然生态自由、无需外区账号，但由于市面上开源工具版本杂乱，加上国内各大手机厂商（小米澎湃OS / 华为鸿蒙 / OPPO ColorOS / vivo OriginOS）极其严苛的后台杀进程机制，新手很容易遇到“订阅导入报错”或“熄屏锁屏就断连”的痛点。

本文将以目前实际验证最稳定、兼容性最好的客户端方案，为您带来**从下载、订阅导入、系统授权到后台防杀保活**的一站式完整教程。

## 二、标准化四步实操流程 (以推荐客户端为例)

### 第一步：获取客户端并完成系统安装
1. **官方专属客户端**：登录机场用户中心，直接下载对应的 Android `.apk` 文件；
2. **开源 ClashMetaForAndroid**：建议从官方 GitHub Releases 仓库（`MetaCubeX/ClashMetaForAndroid`）下载最新稳定版 `.apk`（通常选择 `arm64-v8a` 架构）；
3. **系统安装提示**：在手机上点击安装包，如遇“未知来源应用”安全拦截，点击“设置”勾选“允许来自此来源的应用”即可完成安装。

---

### 第二步：导入机场订阅链接 / 登录凭据
1. 登录机场后台，在「便捷导入」区域点击 **「复制订阅地址」**；
2. 打开客户端软件：
   - **如果是官方专属客户端**：在登录界面填入官网注册的 **邮箱** 与 **密码**，勾选「记住我」，点击「登录 ➔」即可自动同步专线节点（如下图 1）；
   - **如果是 ClashMetaForAndroid**：进入「配置 (Profiles)」➔ 点击右上角「+」➔ 选择「URL (从 URL 导入)」➔ 粘贴复制的订阅链接 ➔ 点击右上角保存磁盘图标完成下载。

### 第三步：系统网络连接请求 VPN 授权 (核心必做)
这是绝大多数新手最容易漏掉或误点导致断网的关键一步：

1. 回到客户端主界面，轻触正中央的 **「快速连接」** 主开关；
2. **系统底层安全弹窗**：Android 系统会自动弹出一个不可绕过的安全提示框：  
   > *“应用想要设置一个 VPN 连接，以便监控网络流量……启用 VPN 后，屏幕顶部会出现一个 ⚿ 图标。”*
3. **务必点击右下角蓝色的「确定」按钮**；
4. 授权成功后，手机顶部状态栏会出现小钥匙 **⚿** 或 **VPN** 标志，代表加密数据隧道已成功建立。

### 第四步：节点挑选、测速与智能分流确认
1. 点击主界面上的 **「节点选择」** 展开专线节点列表；
2. 点击右上角 **「更新节点」** 或 **「测试延迟」** 按钮，系统会向各节点发送轻量探测包；
3. 挑选显示为绿色低延迟（如 30ms ~ 50ms）的香港、日本或新加坡专线节点；
4. 确认底部代理模式为 **【智能分流（规则模式）】**：此时微信、淘宝、抖音保持本地直连不耗流量，海外 Google、ChatGPT 自动走加速专线。

## 三、国产安卓手机“熄屏防断连”三大保活必做设置

如果不进行以下三项设置，国产手机在熄屏 5 分钟后就会将后台代理进程误杀，导致微信接收延迟或海外网络中断：

1. **电池省电策略设置为「无限制」**：  
   进入手机「系统设置」➔「应用管理」➔ 找到该客户端 ➔「省电策略 / 电池优化」，将默认的“智能推荐”更改为 **「无限制」**；
2. **多任务后台卡片「加锁」**：  
   从手机底部上滑进入多任务后台卡片流，长按或向下滑动该应用卡片，点击出现的 **「小锁 🔒」** 图标将其锁住，防止被一键清理误杀；
3. **开启「允许自启动」**：  
   在权限设置中开启“允许应用自启动”和“关联启动”，确保手机重启后服务自动处于就绪状态。

## 四、连接成功检测

打开手机浏览器访问 `https://www.google.com` 验证正常流畅访问；再打开国内视频 App 验证正常播放，即宣告全流程配置圆满成功！
