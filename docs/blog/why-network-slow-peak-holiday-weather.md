# 机场为什么突然变慢？晚高峰、节假日与台风海缆的影响

同一家机场，同一个节点，昨天还很快，今天就卡得打不开视频。很多时候问题既不在你的电脑，也不在机场本身，而在**你和海外服务器之间的那段路**。

下面用三张动图，讲清楚最常见的三种外部原因。

## 一、晚高峰：大家同时上网，国际出口排起长队

<NetSlowdownAnim scene="peak" />

从国内访问海外网站，数据要先经过运营商的**国际出口**，再通过海底光缆出境。国际出口的带宽是有限的，平时够用，但到了晚上 8 点到 11 点半，大量用户同时看视频、打游戏，出口就像晚高峰的收费站：

- 数据包需要**排队**，所以延迟变高；
- 队伍太长时，后来的数据包会被**直接丢弃**，表现为丢包、视频转圈、网页加载一半卡住；
- 白天测速很快、晚上很慢，基本就是这个原因。

**不同线路受到的影响不一样：**

| 线路类型 | 是否经过公网国际出口 | 晚高峰影响 |
| :--- | :--- | :--- |
| 直连 / 公网中转 | 经过 | 明显 |
| IPLC / IEPL 专线 | 不经过（走租用的跨境专线） | 通常较小，但国内入口段仍可能受本地网络影响 |

想了解专线和公网中转的区别，可以看 [IPLC 与 IEPL 专线是什么](/vpn/iplc-iepl-explained)。

## 二、节假日：拥堵从下午一直持续到深夜

<NetSlowdownAnim scene="holiday" />

平日的拥堵集中在晚上几个小时。但到了**春节、国庆等长假**，情况会不一样：

1. **高峰变长**：大家整天在家，上网高峰从下午就开始，一直持续到深夜，拥堵时间比平日长得多；
2. **本地网络变弱**：返乡后用的是小城镇宽带、老家的路由器或手机流量，本地这一段本身就可能成为瓶颈；
3. **特殊时期**：在部分敏感时间段，跨境连接的检测和干扰也可能加强，表现为某些节点突然不可用或频繁断线。

所以长假期间觉得「整天都慢」，不一定是机场出了问题。

## 三、天气与海缆：断了一条，只能绕远路

<NetSlowdownAnim scene="cable" />

国内与香港、日本、东南亚、美国之间的跨境流量，绝大部分依靠**海底光缆**传输。海缆受损的常见原因有：

- **地震与海底滑坡**：例如 2006 年 12 月台湾南部海域地震，同时损坏了多条亚太海缆，影响了整个东亚地区的网络；
- **船锚与渔业作业**：这是海缆受损最常见的原因，台风期间船只避风抛锚也可能增加风险；
- **台风与恶劣天气**：会影响登陆站和维修作业，抢修船要等风浪平息后才能出海。

海缆断了以后，网络不会完全中断，而是**绕行其他线路**。路变远了，延迟就会升高；原本分散在多条海缆上的流量挤到剩下的线路上，可用带宽也会变少。海缆修复通常需要**数周**，这段时间内部分线路都会偏慢。

## 怎么判断是哪一种原因？

| 现象 | 最可能的原因 | 建议 |
| :--- | :--- | :--- |
| 白天正常，每天晚上 8 点后变慢 | 晚高峰拥堵 | 换人少的节点、错峰使用，或考虑专线机场 |
| 长假期间从下午到深夜一直慢 | 节假日高峰 + 本地网络 | 先排查家里网络，再换不同地区的节点 |
| 某一天起所有节点都变慢，持续好几天 | 海缆受损或线路调整 | 留意机场公告和新闻，换到其他地区的节点 |
| 不分时段一直慢，国内网站也慢 | 本地宽带或 Wi-Fi | 参考 [机场速度慢怎么排查](/blog/airport-slow-speed-troubleshooting) |

**通用的应对方法：**

1. **换地区**：香港慢就试试日本、新加坡节点，它们可能走的是不同的海缆和出口；
2. **看公告**：海缆故障、线路调整，机场一般会在官网或 Telegram 频道发通知；
3. **准备备用**：常备一个小额的不限时流量包，主力线路出问题时可以临时切换，参考 [月付、年付和不限时流量包怎么选](/blog/billing-cycles-comparison-guide)。
