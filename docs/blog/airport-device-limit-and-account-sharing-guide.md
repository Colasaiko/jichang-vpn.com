- *“限制 5 台客户端并发”*
- *“不限制同时在线设备数”*

很多用户在购买和使用过程中，常常产生如下疑问：
- **“我家里有一台 iPhone、一台 iPad、一台 Windows 电脑、一台 Mac，这算几台设备？”**

## 一、“设备数限制”的底层技术定义

在机场的后端认证系统（如 SSPanel、V2Board、Xboard 等）中，**“设备数限制”准确的专业术语叫做【同时在线公网 IP 数限制】（Concurrent IP Limit）**。

```
┌────────────────────────────────────────────────────────┐
│             设备数统计原理：看的是【出口公网 IP】        │
├─────────────────┬──────────────────────────────────────┤
│ 场景 1：同一家庭 │ 手机+电脑+平板连接同一个家用路由器WiFi │
│                 │ ➜ 对外表现为【1 个公网 IP】，仅计 1 台!│
├─────────────────┼──────────────────────────────────────┤
│ 场景 2：多地异地 │ 手机用 5G 流量，电脑在公司连接公司网络 │
│                 │ ➜ 产生【2 个不同公网 IP】，计为 2 台!  │
└─────────────────┴──────────────────────────────────────┘
```

1. **家庭 WiFi 局域网 NAT 共享（计为 1 台）**：如果您在家里将订阅分别导入到了手机、平板、台式机、笔记本以及电视盒子上，只要它们连接的都是家里的同一个路由器 WiFi，在机场服务器看来，所有请求全部来自于您家里宽带的同一个对外公网 IP。因此，**在同一个 WiFi 下，哪怕连接 10 台设备，通常也只占用 1 个“设备数”配额！**
2. **异地网络或移动蜂窝网络（按不同 IP 分别计数）**：如果您的手机在户外使用的是移动 5G 网络，而笔记本电脑连接的是公司办公网络，由于两者处于两个完全不同的公网 IP，在服务器端就会被精准记录为 **2 台并发在线**。

## 二、把订阅链接借给朋友用，为什么极易被系统封号？

很多用户为了省钱，会想着买一个大流量套餐与同事、室友或异地朋友拼单共用。然而，绝大多数正规机场的用户协议中都明确禁止**“异地跨区域多人共享”**，其背后的风控算法极其严格：

1. **瞬时跨地域并发检测（瞬移碰撞）**：系统如果在同一分钟内检测到该账号下既有来自北京联通 IP 的流量，又有来自广州电信 IP 的高频数据交换，风控算法会判定该订阅已被公开泄露或存在非法转售行为，直接触发**自动重置订阅密钥**或**账号永久封禁（Ban）**；
2. **连接线程与并发数超标**：当多人同时使用时，并发建立的 TCP 连接数呈指数级上升。超过阈值后，服务器防火墙会自动丢弃超出限额设备的握手包，导致其中某个人突然**全线断网、节点报错超时**；
3. **责任连带风险**：如果合用者中有人使用该节点发送垃圾邮件、触碰高危风控平台或进行违规爬虫，将直接牵连到主账号的安全。

## 三、家庭与小型团队的多设备科学上网最佳方案

如果您确实有多人共用、全屋多设备覆盖或小型跨境团队办公的需求，推荐以下合规方案：

```
┌────────────────────────────────────────────────────────┐
│                   多设备高性价比方案推荐                │
├─────────────────┬──────────────────────────────────────┤
│ 方案 A：全屋软路由│ 单个账号部署在路由器上，全家设备全免配置│
├─────────────────┼──────────────────────────────────────┤
│ 方案 B：不限设备包│ 选购官方明确标注“不限在线设备数”的套餐 │
├─────────────────┼──────────────────────────────────────┤
│ 方案 C：分账号购买│ 个人轻量备用买按量包，主力办公买专线包 │
└─────────────────┴──────────────────────────────────────┘
```

### 1. 方案 A：部署软路由或全屋网关（最优雅、最省钱）
在家庭或小型办公室中，安装一台千兆软路由（运行 OpenWrt / PassWall / Clash Core），在软路由上只登录一个机场订阅。
- 手机、电脑、智能电视连接软路由发射的 WiFi 后，**全部自动走透明代理**；
- 在机场后台仅占用 **1 个在线设备数**，全家数十台智能设备畅快同时上网，且手机端无需安装任何代理软件，极度省电！可参考 [软路由与全屋网关代理指南](/guides/router-gateway-guide)。

### 2. 方案 B：直接挑选“不限制在线设备数”的旗舰套餐
很多实力雄厚的高端专线机场，为了提升商务用户的体验，全线套餐或者高阶套餐**明确标注“不限制同时在线设备数”（如微风网络、灵动云等）**。这类套餐非常适合设备极多的极客玩家或中小型外贸工作室。
