## 一、5 分钟注册自己的美区 Apple ID（不用信用卡） {#register}

1. **准备一个没注册过 Apple ID 的邮箱**，Gmail、Outlook 或 QQ 邮箱都可以。
2. 打开 [Apple 官方的 Apple ID 页面](https://account.apple.com/) 创建账号，「国家或地区」选择**美国**。注册时需要手机号接收验证码，可以用国内手机号。
3. 注册完成后，在 iPhone 的 **App Store** 里登录新账号（只在 App Store 登录，不要在「设置」里登录），系统会提示补全资料。
4. **付款方式选「无」（None）**，账单地址填写一个美国地址（例如免税州的地址），完成后就能免费下载应用。
5. 想买付费应用（如 $2.99 的小火箭），可以买美区 App Store 礼品卡充值到余额。

自己的账号可以开双重认证、自己掌握密码，不会被别人锁，以后更新应用也不用再找共享账号。

## 三、使用须知（务必遵守）

::: danger 只在 App Store 登录
共享账号是很多人一起用的。千万不要在 iPhone「设置」最上方登录 iCloud：一旦登录，账号持有人或其他人改了密码，你的手机可能被「激活锁」锁住，照片和通讯录也可能被同步到这个账号。
:::

1. **只在 App Store 登录**：打开 App Store → 右上角头像 → 拉到最下面「退出登录」→ 再用共享账号登录。
2. **不要登录 iCloud**：不要在「设置」最上方的 Apple ID 里登录，也不要在「信息」「FaceTime」里使用。
3. **不要改任何资料**：不改密码、不改地区、不绑定手机号、不开双重认证。有人一改，所有人都用不了。
4. **遇到「双重认证」提示就放弃**：说明账号状态有变，换另一个账号或稍后再试。
5. **下载完就退出**：回到 App Store 头像页退出，换回你自己的 Apple ID。已经下载的应用可以继续使用，以后更新时才需要再登录。

## 四、怎么用共享账号下载应用？

1. 在共享来源复制一个显示可用的账号和密码。
2. 打开 **App Store** → 点右上角头像 → 拉到底部点「退出登录」。
3. 用共享账号登录。如果弹出「此 Apple ID 尚未在 iTunes Store 使用过」，点「检查」，按提示同意条款即可，**不要填写或修改付款信息**。
4. 搜索要下载的应用，点「获取」或云朵图标下载。如果账号已经买过某个付费应用（如小火箭），点云朵图标就能直接下载。
5. 下载完回到头像页「退出登录」，换回自己的账号。

## 五、账号显示被锁或密码错误怎么办？

共享账号用的人多，苹果的风控会不定期锁定账号，这是正常现象：

- **显示「此 Apple ID 已被锁定」**：换列表里的其他账号。
- **显示密码错误**：可能刚好在更换密码，过几小时再回来看最新密码。
- **所有账号都不能用**：直接照 [第一节](#register) 注册自己的美区 Apple ID，以后不用再担心被锁。

## 七、常见问题

**注册美区 Apple ID 一定要信用卡吗？**

不用。在 App Store 里补全资料时，付款方式选「无」（None）就可以，只要填一个美国地址。

**免费共享的美区 Apple ID 安全吗？**

只在 App Store 登录、下载完就退出，风险很低：App Store 登录不会同步你的照片、通讯录，也不会锁你的手机。真正危险的是在「设置」里登录 iCloud，千万不要这样做。

**用共享账号下载的应用，退出后还能用吗？**

能。退出后应用照常使用，只有更新应用时需要再登录下载时用的账号。

**为什么共享账号经常被锁？**

同一个账号短时间内在大量设备登录，会触发苹果的安全风控。这是共享账号的通病；想一劳永逸，就注册自己的美区账号。

**共享 Apple ID 符合苹果规定吗？**

苹果的服务条款规定 Apple ID 只供本人使用，多人共享不符合条款，账号随时可能被停用。共享账号只建议临时用来下载应用，长期使用请注册自己的账号。

**能用共享账号买东西或充值吗？**

不要。不要在共享账号里绑定付款方式或充值礼品卡，钱会留在别人能登录的账号里。
