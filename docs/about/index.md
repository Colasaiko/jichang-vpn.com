**机场VPN**（[jichang-vpn.com](https://jichang-vpn.com)）是一个独立的**第三方**资料站，主要整理各家机场与网络加速服务的公开信息，也提供 Clash、VPN 协议相关的入门教程和几款免登录的小工具。

本站**不是**任何机场品牌的官网，也不出售任何网络服务。你在本站看到的品牌，都由品牌方自行运营、收费和提供售后。

## 一、本站做什么

- **品牌资料整理**：收录 13 家机场品牌的线路类型、套餐流量、价格、优惠码和客户端支持情况，方便横向比较。
- **入门与排错教程**：Clash 客户端、订阅导入、节点超时、DNS 泄露等常见问题的图文教程。
- **免登录小工具**：套餐筛选、倍率换算、订阅链接检查、优惠码速查等，全部在你的浏览器本地运行。

## 二、资料从哪里来

1. **品牌官网公开信息**：套餐名称、流量、价格、线路类型、解锁说明、设备限制等，主要来自各品牌官网、用户中心的套餐页和官方公告。
2. **本站自行整理**：部分资料（例如优惠码是否可用、官方客户端下载地址、不同周期的折算价格）由本站编辑自行查询、下单页核对后整理。
3. **公开新闻与开源项目**：行业动态、内核与客户端版本信息，来自公开报道和项目的 GitHub 发布页，文中会注明日期。

每个品牌页都标注了资料的更新日期。机场的价格和套餐调整很频繁，**下单前请以品牌官网结算页显示的内容为准**。如果你发现资料过时或有误，欢迎反馈，我们核实后会尽快更新。

为了维持网站运营，本站部分「访问官网」按钮和优惠码属于**推广（返佣）链接**：你通过这些链接注册或购买，本站可能获得一定比例的佣金，**你支付的价格不会因此增加**，使用优惠码通常还会更便宜。

- 推广关系**不影响**资料的整理方式：所有品牌的套餐与价格都按同样的格式列出，优缺点照实写。
- 「推荐」「主力品牌」等标签是本站基于线路类型、价格和资料完整度做出的编辑选择，**不是**官方认证，也**不代表**本站为其服务质量担保。
