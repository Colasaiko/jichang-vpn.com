## 一、技术定义：什么是 IPLC 与 IEPL？

### 1. IPLC（International Private Leased Circuit，国际私有租用线路）
- **本质定义**：IPLC 是电信运营商（如中国电信、中国联通、PCCW、NTT）在两个国家或地区之间铺设的**端到端物理点对点租用数字专线**。
- **物理特性**：在物理层（Layer 1）或时分复用层（TDM / SDH）划分专属的时隙通道，两端直接由运营商的核心数据中心直连。两端之间的数据传输**完全不经过公网互联网路由器**。

### 2. IEPL（International Ethernet Private Line，国际以太网私有专线）
- **本质定义**：IEPL 可以视为 IPLC 的现代化升级版，是基于以太网（Layer 2 / 二层）技术构建的跨国虚拟专用局域网通道。
- **与 IPLC 的微小差异**：
  - IPLC 是传统点对点物理管道，带宽固定；
  - IEPL 支持更加灵活的以太网协议封装（如 VLAN 标签、Q-in-Q），带宽扩容和端口配置更加弹性灵活。
- **用户感知**：在日常跨境网络加速场景中，**IPLC 与 IEPL 的体验与稳定性几乎完全等价**，均代表最高规格的“物理级内网互联”。

## 二、为什么 IPLC / IEPL 专线“不过 GFW 公网审查”？

要理解这一点，必须看清**公网直连中转**与**内网专线**在物理链路上的本质区别：

```
【普通公网直连 / 普通中转模式】
用户电脑 ──► 国内公网 ──► [国际出口交换中心 (包含 GFW 审查与 DPI 探针)] ──► 国际公网海缆 ──► 海外目标
                             ▲
                             └─► 公网高峰期在此处拥塞丢包、被 DPI 探针主动检测与屏蔽！

【IPLC / IEPL 物理专线模式】
用户电脑 ──► [国内 BGP 汇聚机房] ──► (物理光纤专线内网穿透 / 避开公网出海口) ──► [海外原生机房] ──► 海外目标
                                         ▲
                                         └─► 两端机房通过企业级内网以太网互联，压根不经过公网国际出海口！
```

### 1. 物理层面的“路由旁路”
- 大陆对国际互联网的数据监管与审查设备（GFW），全部部署在**中国公网国际出入口局（如北京、上海、广州）的公网光缆交换节点上**。
- 而 IPLC / IEPL 是跨国企业级客户向电信运营商租用的**点对点内网以太网数据通道**。在网络拓扑结构上，它的数据包根本不路由到公网国际出口，而是直接在深圳、上海等两端机房的交换机之间通过专用海底/陆地光缆封闭传输。
- 因此，专线内部的数据**不会触发公网 DPI 深度包检测**，无论使用 Shadowsocks 还是 Trojan，都不会被公网防火墙主动阻断。

### 2. 晚高峰“零拥塞”的物理保障
- 每到晚上 20:00 - 23:00，国内数亿网民访问海外公网，国际出海口总带宽发生严重挤兑拥塞，公网丢包率常飙升至 20%~40%。
- 而 IPLC 专线由于是独占式或企业保障型物理带宽通道，两端机房享有**专属时隙保障**，不受公网拥挤影响，延迟几乎呈一条水平直线（抖动低于 2ms）。

## 四、如何辨别“真 IPLC 专线”与“假冒伪劣挂羊头卖狗肉”？

由于“IPLC”名气极大，市面上不少黑心小机场用廉价的公网中转冒充 IPLC 专线。以下是专业工程师常用的**真伪鉴别三板斧**：

### 1. 晚高峰 MTR 路由跳数诊断（最权威指标）
- 打开命令行工具使用 `mtr` 或 `traceroute` 工具跟踪节点入口机房到海外出口机房的跳数。
- **真 IPLC 表现**：在国内汇聚机房入口之后，**只有 1~2 跳内网保留地址（如 `10.x.x.x` 或 `100.x.x.x`），随后直接到达香港/日本机房的内网网关**，全程看不到任何公网骨干路由跳数（如 `202.97.*` 电信 163 主干网）。
- **假 IPLC 表现**：中间经过了大量的公网骨干网路由跳数，或者在晚高峰出现明显的丢包与延迟飙升。

### 2. 晚高峰长 ping 延迟抖动测试
- 在晚上 21:30 黄金高峰期，对节点连续发送 500 个 ICMP / TCP ping 包。
- **真 IPLC**：平均延迟与最低延迟几乎完全重合（例如 38.2ms / 38.5ms / 39.1ms），丢包率为 0%。
- **假冒专线**：延迟忽高忽低（从 40ms 瞬间跳到 180ms，并伴随丢包）。

### 3. 极端政治敏感期与重大活动测试
- 在某些特殊保障节点，公网直连和普通公网中转会出现大面积阻断失联。
- 真正的 IPLC 内网专线因为走的是运营商企业专网通道，在此期间**依然坚如磐石、秒级就绪**。

## 五、专线的唯一客观不可抗力：恶劣天气与海底光缆

即使是顶级 IPLC 专线，也不是“神仙”。专线唯一可能受到影响的现实物理因素只有：**自然灾害损坏海底物理光缆**。

- 跨国专线的数据最终依然由铺设在几千米深海海底的光纤玻璃管（如 APG、SJC、NCP 海缆）传输。
- 当遭遇**强台风、海底地震或远洋货轮抛锚误伤**导致海缆断纤时，服务商需要将流量紧急调度绕行其他备用海缆。此时短期内可能会出现延迟增加 10~20ms 的情况，这属于全人类通信基建的物理不可抗力。
