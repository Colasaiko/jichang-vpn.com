## 一、为什么品牌不再给订阅链接？

简单来说有四个原因：

1. **防止节点被盗用**：公开的订阅链接容易被爬虫扫到或被人转发，专线带宽会被外人蹭用，付费用户晚高峰反而变卡。
2. **减少配置问题**：第三方软件的时钟偏差、代理没释放、订阅转换失败等问题，专属客户端大多已经内置处理。
3. **线路切换更省心**：海缆故障或机房维护时，客户端可以自动切到备用线路，不用手动更新订阅。
4. **iOS 不用外区账号**：用 Nextin 登录账号即可，不必注册美区 Apple ID 购买小火箭。

每一点的详细解释，见 [为什么机场不提供 Clash 订阅？专属客户端解析](/clash/why-custom-clients-over-clash)。

## 三、常见疑问解答（FAQ）

### Q1: 专属客户端安全吗？会不会收集我的隐私？
**完全无需担忧**。正规主力品牌（如本站收录的推荐品牌）提供的专属定制客户端，其底层核心依然是业界经过长期检验的开源代理内核（如 Mihomo / Xray 内核），只是在外层封装了品牌专用的图形化界面与免配置登录鉴权体系。客户端具备正规系统签名，不注入任何木马，且严格遵循无日志审计原则。

### Q2: 如果我必须在老旧软路由（OpenWrt）上配置，该怎么选择？
如果你的需求非常特殊（例如必须在软路由器里给全屋不支持安装软件的特定智能设备翻墙），专属客户端模式可能不适合你。但对于 **95% 的电脑、笔记本、安卓手机与苹果手机个人用户而言，专属客户端 + Nextin 是目前综合体验最好、最省时、最稳定的方案**。
