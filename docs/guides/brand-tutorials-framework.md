## 二、四大平台专属教程规范 (Windows 与 macOS 实操图解)

每个品牌的实操均严格遵循以下四大平台的教程标准：

### 1. 💻 Windows 电脑专属客户端规范 (6步图文实操)

👉 [**点击查阅：Windows 官方专属客户端完整图文教程专页 (以 firefly 为例) →**](/guides/brand-windows-guide)

- **第一步：下载并解压安装包**：下载 `.zip` 压缩包，解压后双击运行带有图标的 `setup.exe` 安装程序（示例采用 firefly 客户端）；
- **第二步：安装向导执行并运行**：向导快速解包完成，勾选「运行」点击「完成」自动启动客户端；
- **第三步：账号与密码免订阅登录**：输入在品牌官网注册购买的邮箱与密码登录，自动同步 IPLC 专线配置；
- **第四步：主控制面板状态确认**：确认套餐等级、流量额度与到期时间，保持连接状态；
- **第五步：展开功能抽屉开启「系统代理」**：点击右上角功能菜单，务必将「系统代理」开关打开（端游与命令行可开启「虚拟网卡」）；
- **第六步：节点测速、模式切换与一键连接**：挑选低延迟专线节点，确认「智能分流」模式，轻按中央电源图标「快速连接」畅联出海！

### 2. 🍏 macOS 苹果电脑专属客户端规范 (4步图文实操)

👉 [**点击查阅：macOS 官方专属客户端完整图文教程专页 →**](/guides/brand-mac-guide)

👉 [**点击查阅：iOS 苹果端 Nextin 客户端官方保姆级图文实操专页 →**](/guides/brand-nextin-ios-guide)

- **第二步：输入识别码与下一步**：打开 Nextin 极光绿大 “N” 界面，输入官网识别码点击「下一步」；

- **第六步：节点优选与闪电测速**：进入节点列表，点击右上角闪电图标刷新测速，挑选延迟较低的节点；
- **第七步：个人中心服务维护**：长按或左滑服务卡片，一键「更新订阅」平滑容灾。

## 四、使用常见疑问与技术保障

### Q1: 专属客户端连接后，为什么查 IP 显示的是海外？
这是正常现象。专属客户端会自动将你在国内访问国内网站的请求（如微信、百度、淘宝）保留在本地网络直连；而将访问 Google、ChatGPT、YouTube 的请求通过香港、日本或美国专线中继转发，因此目标网站看到的就是海外机房的纯净出口 IP。

### Q2: 遇到突发网络波动或海缆受损怎么办？
专属客户端内置云端故障心跳探测。遇到个别专线维护时，**后台会在 0.1 秒内自动将流量无感平滑切换至备用机房出口**，通常无需用户进行任何操作。如遇极端问题，可直接在用户中心提交在线工单获取技术支持。
