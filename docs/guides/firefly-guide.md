## 一、教程一：Windows 电脑专属客户端实战教程 (6步保姆级图文) {#windows}

👉 [**点击查阅：Windows 官方专属客户端完整 6 步图文实操专页 →**](/guides/brand-windows-guide)

本站 Windows 教程以 firefly 官方专属客户端为**全网图文示范案例**，各大主推品牌客户端架构完全一致：

1. **下载解压**：在 firefly 用户中心下载 Windows 压缩包，解压后双击运行带有 firefly 图标的 `setup.exe` 安装程序；若遇安全提示，点击「更多信息」➔「仍要运行」；
2. **安装向导运行**：向导全自动快速完成解包，勾选「运行」，直接点击「完成」自动启动客户端；
3. **输入凭证登录**：打开客户端，填入官网注册购买的 **邮箱** 与 **密码**，勾选「记住我」与「自动登录」，点击「登录 ➔」；系统全自动下发纯物理 IPLC 专线配置；
4. **主界面状态确认**：确认套餐等级（年付版）、已用流量与到期时间，主界面保持连接就绪状态；
5. **开启「系统代理」（核心必做）**：点击右上角功能菜单抽屉，**务必把「系统代理」开关打开（蓝色）**；如需玩端游或命令行，可开启「虚拟网卡」TUN 模式；
6. **节点选择与一键加速**：点击「节点选择」挑选香港、日本或美国低延迟节点；保持默认推荐的 **「智能分流」**（国内微信直连不耗流量，海外业务走专线）；点击中央大圆钮「快速连接」畅游全球！

## 二、教程二：macOS 苹果电脑专属客户端实操教程 {#mac}

👉 [**点击查阅：macOS 官方专属客户端完整 4 步图文实操专页 →**](/guides/brand-mac-guide)

针对苹果 Mac 电脑（M1/M2/M3/M4 与 Intel 芯片），firefly 提供原生 Universal 通用架构 `.pkg` 专属客户端：

1. **解压安装包**：在官网用户中心下载 macOS 压缩包，解压后点进 `dist` 文件夹，双击打开 `.pkg` 安装包；
2. **运行安装器**：macOS 安装器弹出后，点击「继续」并轻触 Touch ID 或输入开机密码完成安装；
3. **输入凭据登录**：在 Mac「应用程序」打开 firefly 客户端，输入注册邮箱与密码，勾选「记住我」后点击「登录 ➔」；
4. **一键开启加速**：面板自动同步 IPLC 专线节点池，保持默认「智能分流」，点击正中央大圆形电源按钮一键开启加速！

## 三、教程三：Android 安卓手机端实战教程 {#android}

👉 [**点击查阅：Android 官方专属客户端完整 4 步图文实操专页 →**](/guides/brand-android-guide)

1. **下载官方 APK**：在 firefly 用户中心下载专属 Android APK 安装包并完成安装；
2. **账号密码登入**：打开客户端，填入 firefly 注册邮箱与密码登录，自动同步物理专线节点池；
3. **系统 VPN 授权（核心必做）**：首次点击「快速连接」，系统弹出“网络连接请求”安全弹窗，**直接点击「确定」** 授权建立安全加密隧道；
4. **节点测速与后台保活**：展开节点面板刷新延迟并挑选最优专线；在手机应用设置中将 firefly 客户端的省电策略调整为 **「无限制」**，并在多任务栏锁定后台，防止意外断连。

## 四、教程四：iOS 苹果手机 Nextin 快速上手教程 {#ios}

👉 [**点击查阅：iOS 苹果端 Nextin 客户端官方保姆级图文实操专页 →**](/guides/brand-nextin-ios-guide)

针对 iPhone 与 iPad 苹果用户，无需注册海外 Apple ID 付费购买小火箭：

1. **下载 Nextin 应用**：按照教程在 App Store 登录下载 Nextin（提示保护账户时选择「不升级」）；
2. **输入 firefly 站点识别码**：打开 Nextin 极光绿 “N” 界面输入识别码，点击下一步；
3. **输入账号登录**：输入在 firefly 注册的账号与密码完成登入，专线节点与分流规则自动同步；
4. **授权系统 VPN 并连接**：轻触中央电源圆钮，在系统安全弹窗中点击「允许」并验证 Face ID / 锁屏密码；
5. **闪电测速与连接**：进入节点列表，点击右上角闪电 ⚡ 图标刷新测速，挑选延迟较低的节点后连接即可。
