## 一、教程一：Windows 电脑专属客户端实战教程 (6步保姆级图文) {#windows}

👉 [**点击查阅：Windows 官方专属客户端完整 6 步图文实操专页 →**](/guides/brand-windows-guide)

飞猫云的 Windows 官方客户端采用高度集成的现代交互架构，操作流程与本站示范标准完全一致：

1. **下载解压**：在飞猫云官网用户中心下载 Windows 版本压缩包，解压后双击运行带有飞猫图标的 `setup.exe` 安装程序；若遇 Windows Defender 拦截，点击「更多信息」➔「仍要运行」；
2. **安装向导运行**：安装向导数秒内自动解包完成，默认勾选「运行」，直接点击「完成」自动启动客户端；
3. **输入账号登录**：打开客户端，填入你在飞猫云官网注册购买时使用的 **邮箱** 与 **密码**，勾选「记住我」与「自动登录」，点击「登录 ➔」；系统全自动从云端同步分配给你的 2.5G 物理专线节点；
4. **主界面状态确认**：确认套餐等级（星耀版）、剩余流量进度条与到期时间，主界面保持连接就绪状态；
5. **展开功能抽屉开启「系统代理」（核心必做）**：点击右上角功能菜单展开抽屉，**务必把「系统代理」开关打开（蓝色）**；如需玩外服端游（Steam/Apex）或跑命令行，可开启「虚拟网卡」TUN 模式；
6. **节点选择与一键加速**：点击「节点选择」挑选香港、日本或美国 2.5G 低延迟专线；代理模式保持默认推荐的 **「智能分流」**（国内网站直连不耗流量，海外业务走专线）；点击中央大圆钮「快速连接」开始极速出海！

## 二、教程二：macOS 苹果电脑专属客户端实操教程 {#mac}

👉 [**点击查阅：macOS 官方专属客户端完整 4 步图文实操专页 →**](/guides/brand-mac-guide)

飞猫云提供 Universal 通用架构打包的 macOS 专属客户端，原生深度适配 **Apple Silicon (M1/M2/M3/M4 芯片)** 与 **Intel 芯片** 的 Mac 电脑：

1. **解压安装包**：在官网用户中心下载 macOS 压缩包，解压后点进 `dist` 文件夹，双击打开 `.pkg` 安装包；
2. **运行安装器**：macOS 安装器弹出后，点击「继续」并轻触 Touch ID 或输入 Mac 开机密码完成安装；
3. **输入凭据登录**：在 Mac「应用程序」打开飞猫云客户端，输入官网注册邮箱与密码，勾选「记住我」后点击「登录 ➔」；
4. **一键开启加速**：面板自动同步 2.5Gbps 专线节点池，保持默认「智能分流」，点击正中央巨大的圆形电源按钮一键开启极速互联！

## 三、教程三：Android 安卓手机端实战教程 {#android}

👉 [**点击查阅：Android 官方专属客户端完整 4 步图文实操专页 →**](/guides/brand-android-guide)

1. **下载官方 APK**：在飞猫云用户中心下载专属 Android APK 安装包并完成安装；
2. **账号密码登入**：打开客户端，填入飞猫云注册邮箱与密码登录，自动下发专线节点；
3. **系统 VPN 授权（核心必做）**：首次点击「快速连接」，系统弹出“网络连接请求”弹窗，**直接点击「确定」** 授权建立安全隧道；
4. **节点测速与后台保活**：展开节点面板刷新延迟并挑选最优专线；在手机应用设置中将飞猫云的省电策略调整为 **「无限制」**，并在多任务后台任务栏加锁，防止熄屏断连。

## 四、教程四：iOS 苹果手机 Nextin 快速上手教程 {#ios}

👉 [**点击查阅：iOS 苹果端 Nextin 客户端官方保姆级图文实操专页 →**](/guides/brand-nextin-ios-guide)

针对 iPhone 与 iPad 苹果用户，无需注册海外 Apple ID 付费购买小火箭：

1. **下载 Nextin 应用**：按照教程在 App Store 登录下载 Nextin（提示保护账户时选择「不升级」）；
2. **输入飞猫站点识别码**：打开 Nextin 极光绿 “N” 界面输入识别码，点击下一步；
3. **输入账号登录**：输入在飞猫云注册的账号与密码完成登入，专线节点与智能分流规则自动同步；
4. **授权系统 VPN 并连接**：轻触中央电源圆钮，在系统安全弹窗中点击「允许」并验证 Face ID / 锁屏密码；
5. **闪电测速与连接**：进入节点列表，点击右上角闪电 ⚡ 图标刷新测速，挑选延迟较低的节点后连接即可。
