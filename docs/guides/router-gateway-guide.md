对于拥有很多智能家居、Apple TV、PS5 / Switch 主机，或者不想在每一台手机、电脑上单独安装代理软件的家庭用户而言，**旁路由透明网关（Transparent Gateway）** 是终极解决方案。

只需让全屋设备的网关和 DNS 指向一台安装了 OpenWrt 的软路由，即可实现全屋设备**免安装任何软件、开机即用、自动智能分流出海**。

---

## 一、最稳固的家庭网络拓扑：主路由 + 旁路由模式

很多新手喜欢直接用软路由做主路由拨号，一旦配置失误全家直接断网挨骂。因此，**强烈推荐采用「主路由负责拨号与发 Wi-Fi，软路由做旁路网关」的低风险拓扑**：

```
[光猫拨号 / 桥接] ──► [普通硬路由 (如华硕/小米，负责全屋 DHCP 与 Wi-Fi，IP: 192.168.1.1)]
                              │
          ┌───────────────────┴───────────────────┐
          ▼                                       ▼
  【旁路由 (小主机/树莓派)】               【普通智能设备 (手机/电视/电脑)】
  - 运行 OpenWrt / iStoreOS               - 若需透明翻墙：将手机网关设为 192.168.1.2
  - IP 固定为: 192.168.1.2                - 若不需翻墙 (如长辈手机)：保持默认自动获取
  - 运行 OpenClash / PassWall
```

---

## 二、旁路由极速配置三步法

### 1. 固定旁路由的 LAN 口 IP 地址
- 确保旁路由与主路由处于同一网段（例如主路由为 `192.168.1.1`，旁路由设为 `192.168.1.2`）；
- 旁路由的**默认网关与首选 DNS** 均填入主路由 IP：`192.168.1.1`；
- **极其重要**：在旁路由的 LAN 口物理设置中，**关闭 DHCP 服务（勾选“忽略此接口”）**，避免局域网内双 DHCP 争抢导致全家断网！

### 2. 旁路由配置核心分流插件
- 在 OpenWrt 中安装或启动 **OpenClash** 或 **PassWall**；
- 运行模式推荐选择 **TUN 虚拟网卡模式** 或 **TProxy 模式**；
- 开启 Fake-IP 模式与国内直连白名单。

### 3. 需要翻墙的设备手动指定网关
对于想要享受无感加速的电脑、Apple TV 或主机：
- 打开设备的 Wi-Fi 设置，将 IP 获取方式从“自动”改为“手动 / 静态”；
- **IP 地址**：`192.168.1.88`（同网段未占用 IP）；
- **子网掩码**：`255.255.255.0`；
- **路由器 (网关)**：填写旁路由 IP **`192.168.1.2`**；
- **DNS**：填写旁路由 IP **`192.168.1.2`**。

保存后，该设备的所有网络出站流量都会经过旁路由智能分流，彻底摆脱单机客户端软件的束缚！
