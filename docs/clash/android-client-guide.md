在安卓（Android）手机上使用代理工具，很多用户会遇到几个典型痛点：
- 🔍 **不敢在第三方小网站随便下载 APK**，担心被二次打包植入挖矿木马；
- 🔋 **后台频繁被国产手机系统（MIUI/澎湃OS、鸿蒙、ColorOS、OriginOS）无情杀掉**，刚切出软件代理就断线；
- 📱 **微信和国内银行 App 频繁被代理干扰**，导致微信弹异地登录提醒或健康码打不开。

本文为你推荐目前安卓生态最主流、安全且经过检验的开源客户端，并详解**分应用代理与防杀后台保活设置**。

## 二、保姆级上手工作流（以 CMFA 为例）

### 步骤 1：安全下载与安装
- **切忌**在百度随意搜索“安卓翻墙下载”下载所谓“极速破姐版”；
- 建议前往 GitHub 官方 Releases 仓库或正规服务商后台直接下载官方编译的 APK 文件（ARM64 架构即可适配 99% 的现代安卓手机）。

### 步骤 2：导入订阅配置
1. 打开 CMFA，进入主界面的 **「配置 (Profiles)」**；
2. 点击右上角 `+` 号，选择 **「URL (从 URL 导入)」**；
3. **名称**：随意填写（如：主力专线）；
4. **URL**：粘贴机场提供的订阅链接；
5. 点击右上角「保存」，客户端会自动拉取节点，返回主页勾选该配置。

### 步骤 3：选择分流模式
- 在主界面点击「运行模式 (Mode)」；
- 务必选择 **「规则 (Rule)」** 模式，这样国内流量直连，海外业务才走代理；
- 切勿选择「全局 (Global)」，否则微信和淘宝都会绕道海外，导致银行 App 报错。

### 步骤 4：启动 VPN 服务
- 点击顶部正中央的灰色开关「点击启动 (Click to Start)」；
- 首次启动系统会弹出安卓系统的**网络连接请求（VPN 授权弹窗）**，点击「确定/允许」即可成功翻墙！

## 三、核心必设技巧：分应用代理（Bypass 银行与国服手游）

安卓用户**强烈建议开启「分应用代理」**，让国产银行、微信、钉钉和王者荣耀等应用完全绕过代理软件：

1. 进入 CMFA 的「设置 (Settings)」→「网络 (Network)」；
2. 找到 **「分应用代理 (Access Control)」** 开关并开启；
3. **访问控制模式**：选择 **「仅允许选中的应用通过 (Allow Selected Applications)」** 或 **「禁止选中的应用通过 (Bypass Selected Applications)」**；
4. 勾选需要翻墙的应用（如：Chrome、YouTube、Twitter、Telegram、ChatGPT）；
5. 这样微信、网易云音乐、招商银行、微信支付等关键软件将全部走手机真实 SIM 卡/Wi-Fi 直连，彻底告别异地风控！

## 四、破解国产手机“杀后台断连”神坑（各大品牌保活指南）

国产手机厂商为了省电，默认策略是在手机锁屏或切换应用 5 分钟后，强制清理后台常驻的 VPN 进程。解决办法非常简单：

### 1. 小米澎湃 OS / MIUI
- 打开「设置」→「应用设置」→「应用管理」→ 找到「Clash Meta」；
- **自启动**：允许自启动、允许被关联启动；
- **省电策略**：从“智能推荐”修改为 **「无限制 (No restrictions)」**；
- 在最近任务卡片中，**长按该应用卡片并点击“小锁头”图标加锁**。

### 2. 华为 HarmonyOS / 荣耀 MagicOS
- 打开「设置」→「电池」→「应用启动管理」；
- 找到该客户端，关闭“自动管理”，在手动管理中开启：**允许自启动、允许关联启动、允许后台活动**。

### 3. vivo OriginOS / OPPO ColorOS
- 进入应用详情，开启“后台高耗电允许运行”，并在多任务卡片页面向下滑动加锁锁定。

- 自带手机防休眠唤醒；
- 预先排除国内常见银行与社交软件；
- 下载 APK 登录即可秒用，小白甚至不需要了解什么是“订阅 URL”。
